# CBCT 三维重建系统

从**锥形束 CT（Cone-Beam CT, CBCT）原始 X 线投影数据**出发，实现一套完整的三维重建管线：几何标定 → 灰度域转换 → FDK 解析重建 / 迭代重建 → 定量评估 → 三维可视化，并提供一个 **PyQt5 + VTK 桌面软件** 直接查看三维结果。

---

## 一、任务定义

**输入**：普爱医疗（Perlove）PLX7500 三维 C 形臂采集的一次腰椎检查的原始投影数据——多帧 X 线投影（`.dic`，978×978、16bit、191 帧）。

**输出**：
1. 三维体数据（400³，0.5mm 各向同性体素）
2. 三正交切面（轴向/冠状/矢状）
3. 三维骨骼表面/体渲染
4. 与厂商重建结果（ground truth）的定量对比指标

**核心挑战**：
- 投影数据**不含几何标定参数**（投影角、源-探测器/源-旋转中心距离均未写入 DICOM），需从数据反推；
- 患者身体（~400mm）远大于探测器在等中心的覆盖（~185mm），存在**严重横向截断**；
- 数据是 "For Presentation" 显示值，灰度经过处理，需正确转换到线积分域。

## 二、背景与原理

### 2.1 CBCT 成像

CBCT 是 C 形臂 / 牙科 / 放疗引导常用的三维成像方式。X 线源绕患者旋转，平板探测器连续采集二维投影，再由投影反演三维衰减系数分布（CT 图像）。相比螺旋 CT，CBCT 采用锥形束 + 一次旋转，成像快、剂量相对低，但散射与截断更严重。

### 2.2 重建模型

重建的核心是求解线性逆问题：

```
Pf = g
```

其中 `f ∈ R^{N³}` 是待重建的体素化衰减系数，`g ∈ R^{F×H×W}` 是投影（线积分），`P` 是锥束前向投影算子。投影是**线积分**：探测器测到的 X 线强度 `I` 满足比尔-朗伯定律

```
I = I₀ · exp(−∫ μ dl)     ⟹     p = −ln(I / I₀) = ∫ μ dl
```

因此重建前需把强度域投影做**负对数**转成线积分域。

### 2.3 几何模型

锥束圆轨迹几何（源绕 z 轴旋转，半径 R，源-探测器距离 D）：

```
t = x·cosβ + y·sinβ         体素沿"源-原点"方向坐标
s = −x·sinβ + y·cosβ        体素垂直方向坐标
U = R − t                   源到体素距离
u_det = D·s / U             探测器列坐标(mm)
v_det = D·z / U             探测器行坐标(mm)
```

放大倍数 `M = D/R` 决定物体在探测器上的缩放。

## 三、算法详解

### 3.1 FDK 解析重建（`python/fdk_ref.py`, `fdk_cuda.py`）

Feldkamp–Davis–Kress（FDK，1984）是圆轨迹锥束的近似滤波反投影，三步：

1. **余弦加权**：`p' = p · D / √(D² + u² + v²)`
2. **斜坡滤波**（沿探测器 u 方向，R-L 核）：`p̃ = F⁻¹{ |ω| · F{p'} }`
3. **加权反投影**：`f(x,y,z) = Σ_β p̃(β, u, v) · R²/U²`

反投影是计算量最大的一步（O(F·N³)），在 GPU 上并行（每个体素一个线程）。

### 3.2 几何标定（体数据反推，`python/geometry.py`）

由于投影 DICOM 无几何参数，采用**"合理假设 + ground truth 反推"**：

- **假设**：等角间距扫描、圆轨迹、旋转轴在探测器行方向；
- **反推**：以厂商重建结果（`_3D.raw`）为真值，在参数空间网格搜索，最大化重建与 GT 的相关性。

最终确定（经球体自洽验证收敛）：

| 参数 | 值 | 确定方法 |
|---|---|---|
| 扫描范围 | **200°**（短扫描） | 帧数 + 相关性扫描 |
| 放大倍数 M=D/R | **1.6** | 相关性峰值 |
| 源-旋转中心 R | 800 mm（D=1280 mm） | R 在 600–1500 不敏感 |
| 探测器列中心 u0 | (W−1)/2 − 24 | 物体投影质心正弦拟合 |
| 旋转轴方向 | 探测器 v（行）方向 | 帧间差分方向分析 |

### 3.3 灰度域转换（负对数）

实测投影为强度域（空气亮 > 物体暗），重建前做：

```
p = −ln(I / I₀),   I₀ = 空气区强度(99.9 分位)
```

### 3.4 横向截断与截断外推（`fdk_cuda.py` 的 `filter=2`）

患者身体投影超出探测器，FDK 假设"投影在探测器边界衰减到 0"被违反，斜坡滤波的 circular wrap-around 会把边界物体卷到对侧，导致重建失败（物体偏移）。

**解法**：投影在 u 方向左右各**线性外推** `pad` 像素（衰减到 0），再做斜坡滤波。实测把滤波重建的相关系数从 0.24 提升到 0.44，并**恢复骨骼细节**。

### 3.5 迭代重建 SART / ASD-POCS（`python/asd_pocs.py`）

基于压缩感知的迭代重建，用于稀疏角度/截断：

```
min ‖f‖_TV   s.t.  ‖Pf − g‖ ≤ ε,  f ≥ 0
```

- **SART**：`f ← f + (β/F)·Pᵀ(g − Pf)`（数据一致性，逐角度）；
- **非负约束**：`f = max(f, 0)`；
- **TV 最小化**：最速下降 `f ← f − dα·∇TV(f)/‖∇TV(f)‖`，自适应步长 `dα = α·d_pocs`。

实现为三个 GPU kernel（前向投影 splat / 反投影采样 / TV 梯度）。

## 四、系统架构

```
原始投影(.dic) ──读取──▶ 强度投影 ──负对数──▶ 线积分投影
                                                    │
                    ┌───────────────几何标定─────────┤
                    ▼                               ▼
              FDK 解析重建                     SART/ASD-POCS 迭代重建
         (加权→滤波→反投影, CUDA)              (前向/反投影+TV, CUDA)
                    │                               │
                    └──────────▶ 体数据(400³) ◀──────┘
                                    │
                          ┌─────────┼─────────┐
                          ▼         ▼         ▼
                     定量评估    NIfTI 导出  三维可视化
                    (corr/Dice) (3D Slicer)  (PyQt5+VTK / HTML)
```

**计算后端**：CUDA（numba.cuda 的 NVVM JIT，反投影在 GPU 上并行，~100× 加速；本机无 MSVC，故用 numba.cuda 而非 nvcc C++，C++ 版见 `cuda/fdk.cu`）。

**几何正确性保证**：CPU 参考实现（`fdk_ref.py`）与 CUDA 实现逐位一致（corr=1.0）；球体体模自洽重建 corr=0.96、GT 前向投影自洽 corr=0.91，证明前向/反投影算子与几何标定正确。

## 六、实验结果

| 方法 | 相关系数 | 骨骼 Dice | 说明 |
|---|---|---|---|
| 球体体模自洽（200° 短扫描） | 0.96 | — | 算法正确性验证 |
| GT 前向投影自洽 | 0.91 | — | 复杂解剖结构正确性 |
| 无滤波反投影 | 0.63 | 0.47* | 均匀椭圆，无骨骼细节 |
| **截断外推 + 斜坡滤波** | **0.44** | **0.29** | **骨骼细节可见（视觉最佳）** |
| SART / ASD-POCS | 0.38 | 0.37 | 横向截断下过拟合 |

*无滤波的 Dice 0.47 是"椭圆覆盖骨骼"的巧合，非真实骨骼对齐。

**关键结论**：
1. FDK 实现与几何标定正确（球体/GT 自洽 corr ≥ 0.91）。
2. 横向截断是核心瓶颈：不处理时斜坡滤波失效（0.24），截断外推后恢复骨骼细节（0.44）。
3. 迭代重建（SART/ASD-POCS）在横向截断下**没有超过**外推+滤波——截断使投影数据不一致（零阶矩变化 ~19%），SART 第 2 次迭代起过拟合；论文的 ASD-POCS 优势在稀疏角度，不适用于本数据的横向截断。

## 七、快速开始

### 7.1 环境

- Windows + NVIDIA GPU（RTX 4090 实测）
- Python 3.11（anaconda）：`numpy scipy pydicom numba nibabel plotly matplotlib`

## 九、限制与展望

- **横向截断**是数据物理硬约束（探测器外投影信息缺失），解析与迭代方法均无法完全恢复，需更大探测器 FOV 的硬件，或截断感知的深度学习重建。
- 数据为 "For Presentation" 显示值，重建灰度与 GT 的 HU 标定存在尺度差异（不影响结构）。
- 迭代重建（ASD-POCS）在稀疏角度场景更有优势，可迁移到低剂量稀疏采样数据。
- 桌面软件内存占用 ~7GB（400³ 双体数据 + 4036 万三角形等值面），可降采样等值面优化。

## 附：关键几何/算法公式速查

FDK 反投影（体素 `(x,y,z)`，投影角 `β`）：

```
t = x cosβ + y sinβ
s = −x sinβ + y cosβ
U = R − t
u = D·s/U / det_pitch + u0
v = D·z/U / det_pitch + v0
f(x,y,z) += p̃(β, u, v) · R² / U²
```

斜坡滤波核（R-L，频域）：`H(ω) = |ω|`，离散 `h(0)=1/(4d²)`，`h(n) = −1/(nπd)²`（n 奇数）。
