## 1. 项目是什么

从**锥形束 CT（CBCT）原始 X 线投影数据**重建**三维体数据**的完整管线，附带定量评估与三维可视化。

- **输入**：一次腰椎检查的多帧 X 线投影（`.dic`，978×978、16bit、191 帧，200° 短扫描）
- **输出**：400³ 体数据（0.5mm 体素）+ 三正交切面 + 三维骨骼渲染 + 与设备方重建结果的定量对比
- **代码**：`python/`（算法）、`app/`（PyQt5+VTK 桌面软件）、`cuda/`（C++ 版，未编译）
- **状态**：可完整跑通。核心算法正确性经球体/GT 自洽验证（corr ≥ 0.91）；对真实数据的最佳结果是「截断外推 + 斜坡滤波」，corr 0.44、骨骼细节可见。

## 2. 原理

### 2.1 重建模型

重建是解线性逆问题 `Pf = g`：

- `f`：待求的三维衰减系数分布（体素化）；
- `g`：投影，即每条射线穿过的密度线积分；
- `P`：锥束前向投影算子。

投影与强度的关系由比尔-朗伯定律给出：`I = I₀·e^(−μL)`，故线积分 `p = −ln(I/I₀)`。**重建前必须把强度域投影做负对数转成线积分域**。

### 2.2 几何模型

圆轨迹锥束（源绕 z 轴转，半径 R，源-探测器距离 D）：

```
t = x·cosβ + y·sinβ      s = −x·sinβ + y·cosβ
U = R − t                 u_det = D·s/U,  v_det = D·z/U
```

放大倍数 `M = D/R`。

### 2.3 FDK 重建

FDK（Feldkamp–Davis–Kress, 1984）是圆轨迹锥束的近似滤波反投影，三步：

1. **余弦加权** `p' = p·D/√(D²+u²+v²)`
2. **斜坡滤波**（沿探测器 u 方向，R-L 核，频域 `|ω|`）
3. **加权反投影** `f = Σ_β p̃·R²/U²`（计算量最大，GPU 并行）

### 2.4 迭代重建

SART（数据一致性）+ TV 最小化（压缩感知正则化），目标 `min ‖f‖_TV s.t. ‖Pf−g‖≤ε, f≥0`。三个 GPU kernel：前向投影 splat / 反投影采样 / TV 梯度。

## 3. 为什么这么做（关键决策与理由）

| 决策 | 理由 |
|---|---|
| 主用 **FDK**，迭代作补充 | FDK 是术中 CBCT 主流，解析重建快、够用；迭代用于稀疏角度/低剂量 |
| 几何用**「假设 + 体数据反推」** | 投影 DICOM 无几何参数，只能反推；有设备方体数据当 ground truth 兜底 |
| 用 **numba.cuda** 而非 nvcc C++ | 本机无 MSVC 编译器，numba 的 NVVM JIT 不需 host 编译器；反投影 ~100× 加速 |
| 最终用**截断外推 + 斜坡滤波** | 横向截断下实测最优；迭代重建（SART/ASD-POCS）反而过拟合（见 §4） |

## 4. 目前存在的问题

### 4.1 横向截断（核心硬约束）

病人身体（~400mm）远大于探测器等中心覆盖（~185mm），投影横向截断约一半。后果：

- 斜坡滤波的 FFT circular wrap-around 把边界物体卷到对侧，直接滤波重建失败（corr 0.24）；
- 外推（线性衰减到 0）后滤波恢复骨骼细节，但**探测器外的信息真实缺失**，边缘仍有误差（骨骼 Dice 0.29）。
- **这是物理硬约束**，解析与迭代方法都无法凭空恢复缺失数据。

### 4.2 灰度域不精确

数据是 "For Presentation" 显示值（无 VOI LUT / Rescale tag），负对数得到的线积分与设备方 GT 的 HU 标定存在**灰度尺度差异**（不影响结构，但影响定量 HU 值）。逐像素空气归一化、各种灰度变换均无法消除。

### 4.3 几何标定精度有限

相关性对 R、u0 等参数不敏感（存在平台区），标定可能有**残余偏差**（体现为骨骼位置与 GT 不完全对齐）。当前 M=1.6、u0=(W−1)/2−24 是相关性峰值，但精度受限于「相关性」这个弱目标函数。

### 4.4 迭代重建无效

SART 第 2 次迭代起过拟合截断伪影（corr 0.62→0.34），TV 只轻微抑制（0.38）。根因：横向截断使投影数据不一致（零阶矩变化 ~19%），非稀疏角度问题——论文里的 ASD-POCS 优势不适用。

### 4.5 工程层面

- 桌面软件内存 ~7GB（400³ 双体数据 + 4036 万三角形等值面），可降采样优化；
- `cuda/fdk.cu` 因无 MSVC 未编译；
- 数据仅单次检查，结论的泛化性未验证；
- 重建灰度未标定到标准 HU。

## 5. 厂家（业界）通常怎么处理

| 问题 | 业界常规做法 |
|---|---|
| **几何标定** | 出厂用**体模标定**（金属小球阵列 / 栅格），估计投影矩阵（DLT / 针孔模型），参数写入设备；规范见 **AAPM TG-238**。本项目数据属于「参数未随数据导出」的非典型情况 |
| **横向截断** | ① 硬件：更大探测器 FOV、**探测器偏置扫描**（offset detector）扩展视野；② 软件：投影数据外推、截断感知的迭代重建 |
| **散射校正** | 硬件加反散射栅格；软件做散射估计与扣除（卷积核法、Monte Carlo、基于模型的散射校正） |
| **射束硬化** | 水模/多材料模体标定 + 多项式校正 |
| **灰度/HU 标定** | 水模标定，建立线性 HU 映射（本项目 GT 即经过 RescaleIntercept=−300 标定） |
| **重建引擎** | GPU 加速 FDK（术中实时）；低剂量时用统计迭代 / 深度重建 |
| **金属伪影** | MAR（金属伪影抑制） |
| **深度学习** | 去噪（如 NAFNet）、截断感知重建、2D/3D 配准、低剂量图像恢复 |

一句话：**商用设备把几何标定、散射、射束硬化、HU 标定都做在设备/软件内部，数据导出时通常已是"标定好的干净线积分 + 完整几何参数"；本项目面对的"缺几何 + 横向截断 + 显示值灰度"是数据不完整造成的退化场景。**

## 6. 未来的着力点

按「投入产出比」排序：

### 6.1 短期（数据内可做）
- **更精确的几何自标定**：用「投影一致性条件」或「GT 前向投影配准」替代弱的相关性目标，提升 M/R/u0 精度，改善骨骼对齐。
- **截断感知的迭代重建**：SART 只约束探测器内数据 + 对截断边界加权 + 更强的结构先验（各向同性 TV / 字典），缓解过拟合。
- **等值面降采样**：把桌面软件内存从 7GB 降到 ~2GB。

### 6.2 中期（需补充数据/标定）
- **灰度标定到 HU**：用设备方 GT（已标定 HU）拟合重建灰度 → HU 的映射，使结果可定量。
- **散射校正**：估计并扣除散射（卷积核法起步），改善软组织对比度。
- **多组扫描验证**：用 5 组投影/体数据卷交叉验证几何标定的稳定性与泛化性。

### 6.3 长期（新方向）
- **深度学习重建**：截断感知 + 去噪 + 低剂量（本项目姊妹方向 NAFNet 去噪已有积累，可迁移到重建域）。
- **稀疏角度 / 低剂量重建**：ASD-POCS 的优势场景，换到 30–60 投影的稀疏采样上会有更好表现。
- **4D CBCT**（运动/动态）：参照论文《基于 C 型臂的 4D CBCT 重建算法研究》的 PICCS + 2D/3D 配准路线。

## 7. 快速上手

```bash
cd python
python run_all.py 1094408        # 一键: 读投影→负对数→CUDA重建→评估→NIfTI→HTML
cd examples && python generate_phantom.py   # 球体自洽验证(无需真实数据)
cd app && python main.py 1094408  # 桌面软件(三维骨骼 + 三正交切片)
```

**关键文件**：`fdk_cuda.py`（CUDA FDK + 截断外推）、`fdk_ref.py`（CPU 参考）、`geometry.py`（几何参数）、`asd_pocs.py`（迭代重建）、`evaluate.py`（评估）。

**已确定的几何**：200° 短扫描、M=D/R=1.6、R=800mm/D=1280mm、u0=(W−1)/2−24、旋转轴沿探测器行方向。
